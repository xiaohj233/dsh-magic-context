# dsh-magic-context-adapter

Harness-compatibility contracts for `dsh-magic-context` — the community port
of Magic Context to DeepSeek Harness. Canonical session keys, harness flags,
model-reference mapping, and DSH runtime integration points.

- **runtime**: bundled into the main package (no separate install needed)
- **types**: consumed at build time by the main package
- Upstream: https://github.com/cortexkit/magic-context (MIT)
